# План: сайт-каталог премиальных красок с колеровкой

Сайт-визитка магазина с каталогом. Корзины и онлайн-оплаты нет: заказ через заявку, телефон или мессенджер. Главное позиционирование: колеруются только премиальные краски. Оно проходит через главную, каталог, карточку товара и страницу «Колеровка».

Стек: AgeCMS (ядро подключено submodule `vendor/agecms`), своя тема `site/themes/kolerovka` и свой модуль каталога `site/modules/catalog`, контент в `content/`. Статус: каркас собран (тема, каталог, колеровка, формы, контакты), данные демонстрационные.

## Что значит «под вопросом» в ТЗ

Пометка означает, что заказчик сам ещё не решил, будет ли пункт. Поэтому такие пункты делаем отключаемыми блоками, решение принимает заказчик без правки кода.

| Пункт | Как закладываем |
| --- | --- |
| Форма заявки на колеровку | блок формы включается и выключается на странице; без него остаются телефон и мессенджеры |
| Метка «Колеруется / Не колеруется» | поле товара и переключатель вывода метки в теме |
| Фото магазина и оборудования | блок галереи, пустой не выводится |
| NCS | строка в блоке «Способы колеровки», включается флагом |
| Яндекс.Карта виджетом | блок карты; если нет, ссылка «Построить маршрут» |
| Раздел «Прочие краски» | категория каталога, пустая не выводится |

## Структура страниц

| Страница | Содержимое |
| --- | --- |
| Главная | hero, «Почему мы», витрина 4-8 позиций, блок колеровки с акцентом на премиум, контакты и карта, кнопки «Позвонить» и «Telegram/Max» |
| О нас | текст, оборудование, преимущества, фото (если будет) |
| Каталог | сетка карточек, фильтры по бренду, типу (интерьерная, фасадная, универсальная) и признаку «Колеруется» |
| Товар | галерея 2-4 фото, бренд, описание, характеристики, метка «Доступна колеровка», кнопка «Уточнить наличие / Заказать» |
| Колеровка | процесс, оборудование, сроки, список премиум-брендов и линеек, по образцу и по RAL, форма заявки |
| Контакты | адрес, телефон, email, Max и Telegram, график, карта, форма с согласием на ПДн, реквизиты |
| Полезное, Доставка и оплата | опционально, после решения заказчика |

| 0 | Уточнение с заказчиком | ответы на список вопросов, список брендов и линеек, контакты, реквизиты | - |

## Принятые решения по умолчанию

- Цены в карточке не показываем, пока заказчик не скажет иначе: «Уточнить наличие и цену».
- Заявки по умолчанию отправляем в Telegram и на email; канал меняется настройкой.
- Админка AgeCMS даёт заказчику править страницы и товары сам.
- Фильтры работают на готовых данных без перезагрузки, ссылки на отфильтрованный каталог можно сохранить.
- Характеристики и фото берём только с разрешённых источников: официальные сайты брендов, права уточняем у заказчика.

## Риски

| Риск | Что делаем |
| --- | --- |
| Нет списка колеруемых брендов | без него не собрать блок «Колеровка» и фильтры; первым вопросом заказчику |
| Нет фото и описаний товаров | наполнение откладывается; делаем с данных официальных сайтов, права уточняем |
| Нет логотипа и стиля | закладываем этап дизайна, согласовываем макет до вёрстки |
| Решения по пунктам «под вопросом» не приняты | блоки отключаемые, запуск не ждёт |
