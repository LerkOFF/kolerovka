# kolerovka

Сайт-каталог магазина красок с услугой колеровки (Донецк): премиальные бренды, каталог с поиском и фильтрами, страница колеровки с выбором оттенка RAL, заявки и контакты.

Движок AgeCMS подключён как submodule `vendor/agecms` и здесь не правится. Своё лежит в репозитории:

| Папка | Что |
| --- | --- |
| `site/themes/kolerovka` | тема: макет, блоки страниц, стили, значки, шрифт Onest |
| `site/modules/catalog` | модуль каталога: таблицы товаров и фасовок, публичные `/katalog`, админка с поиском, фильтрами, массовой правкой цен и импортом CSV |
| `content` | страницы, меню, настройки и демо-товары в JSON, загружаются `scripts/seed.php` |
| `deploy` | пример конфигурации nginx |
| `docs/PLAN.md` | план работ и вопросы к заказчику |

```bash
git clone --recurse-submodules <репозиторий> && cd kolerovka
scripts/dev.sh              # собрать, установить, загрузить content/, запустить на http://127.0.0.1:8098/
scripts/refresh.sh          # после правки темы или модуля, пока сервер запущен
scripts/deploy.sh           # выкладка: git push, затем на сервере git pull и пересборка
```

Состояние локального экземпляра (база, кэш, загрузки, пароль админки) лежит в `/tmp/kol-dev`, не в репозитории. На сервере сайт собирается скриптом `scripts/server-update.sh` из клона репозитория: данные сайта (`data/`, загрузки, кэш) при обновлении не трогаются.

Что настраивается без правки кода (админка `/admin/`): страницы и тексты, контакты и график, ссылки на Telegram и Max, карта, реквизиты, товары и цены, показ цен на сайте, метка «Колеруется», раздел «Прочие краски».
