# kolerovka

Сайт-каталог магазина красок с услугой колеровки: премиальные бренды, карточки товаров с фильтрами, страница колеровки, заявки и контакты. Движок AgeCMS подключён как submodule `vendor/agecms`, тема и контент лежат в этом репозитории.

Статус: планирование, код не начат. План и этапы: [docs/PLAN.md](docs/PLAN.md).

```bash
git clone --recurse-submodules <репозиторий>
```
